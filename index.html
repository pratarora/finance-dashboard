What this app does

It turns your bank and credit-card CSV exports into one categorized ledger in CHF, with charts for income, spending and savings, trends, recurring payments and unusual transactions. It runs entirely in your browser. Nothing is sent to a server, and the page only talks to Google if you choose to connect Google Drive.

Quick start

  1. Click + Load CSV Files (or drag files onto the page) and add your bank transactions export and your card invoice file(s). You can select several at once.
  2. Use the date slider above the ledger to choose a period, and the filters to narrow the view.
  3. Fix any wrong category right in the ledger. The app can remember the fix for that merchant.
  4. Decide how to keep your data (see Saving your data) so you do not have to re-upload.

Supported files

  • Bank transactions: a semicolon-separated export with a Trade date; header row (the format used by the bank this dashboard was built for).
  • Card invoice: a semicolon-separated file with Booking text and Card number columns, optionally starting with sep=;.
  • The file type and text encoding are detected from the contents, so filenames do not matter. Unrecognized files are ignored with a message.
  • Other banks' formats are not supported yet.

Adding new data and duplicates

Load new files any time. Each transaction is compared with what is already stored (by transaction number or by date, merchant and amount). Existing ones are skipped and new ones are added, and the status line tells you how many of each. Two identical purchases on the same day are both kept.

Card settlements are not double-counted

Payments from your bank account to your card, and the matching credits on the card invoice, are put in Excluded (Card Settlement) so the itemized card purchases are not counted twice. They stay visible: choose that category in the filter, or tick Show excluded duplicates.

Filters and the ledger

  • Date range: drag the two slider handles or type exact dates. All resets it. The range applies to the KPIs, all charts and the ledger.
  • Category, source and search filter the ledger table. The line chart and pie chart below the ledger always show exactly the rows the ledger shows. The pie can be grouped by category, merchant or source.
  • Refunds and reimbursements reduce spending instead of counting as income. Only salary-type credits count as income.

Recategorizing and rules

Change the category in any ledger row. If other transactions from the same merchant have a different category, the app asks whether to apply the change to all of them and remember it as a rule for future uploads. Rules are listed under Saved Category Rules where you can delete them. Reset Edits clears all your edits and rules.

Insights below the ledger

  • Month-over-month: the latest month in your range against the previous month and the average of earlier months, per category.
  • Cumulative savings and forecast: income minus spending over time with a straight-line trend 3 months ahead. The latest month may be incomplete, which can skew the trend.
  • Top merchants and Recurring / subscriptions (3+ months, similar amounts).
  • Unusual transactions: large outliers within a category and large one-off payments.

Saving your data

Pick what suits you. They can be combined.

1. Remember data in this browser (checkbox)

Ticked: a copy is kept in this browser so it is there next time. Unticked: nothing is stored in the browser, any existing local copy is erased, and your data lives only while the tab is open. You will be warned before closing if it has not been saved anywhere else. Untick it on shared computers.

2. Google Drive (encrypted, per session)

Connect Google Drive signs you in for this session only. Your data is encrypted in your browser with a passphrase you choose (AES-256) before it is uploaded, so Google stores only ciphertext. The app can only see files it created. You can keep several named datasets (for example Personal and Demo), each with its own passphrase, and pick one when you connect or with Switch dataset. Closing the tab or clicking Disconnect ends the session.

If you forget a dataset's passphrase it cannot be recovered. To delete a dataset, delete its finance_data*.enc.json file in Google Drive.

3. Link data file (Chrome or Edge, opened as a normal page)

Saves your data to a JSON file you choose on your computer and reads it back next time. This is not encrypted.

4. Backup JSON / Restore JSON / Clear Data

Backup JSON downloads everything (transactions, edits, rules) as a file, which is not encrypted, so store it safely. Restore JSON merges a backup into what is loaded. Clear Data deletes the stored data, including the open Google Drive dataset and the linked file if any.

Privacy

  • Your CSVs are processed locally in your browser. The page itself contains no data.
  • Google Drive is used only if you click Connect, and only for the encrypted dataset file.
  • This tool is for personal bookkeeping. Categories are automatic guesses, so check them, and it is not financial advice.
  • Read the Privacy Policy and the Terms & Disclaimer.

Troubleshooting

  • Data did not come back next time: the browser copy is off (checkbox) or the browser blocks storage. Connect Google Drive or use Backup JSON.
  • Link data file does nothing: use Chrome or Edge, and open the dashboard as its own page, not embedded in another site.
  • Google sign-in error "access_denied": your account must be allowed to use the app.
  • Google sign-in error "origin_mismatch": the page address is not registered with the app. Settings can take a while to apply.
  • A file is "not recognized": it must be the semicolon-separated bank or card export described above.
  • Wrong numbers right after loading: check for incomplete months and recategorize anything misclassified.
